# Hemant Achhami Portfolio

Static one-page developer portfolio for `https://hemantachhami19.github.io/`.

The site is built with plain HTML, CSS, and JavaScript so it can be deployed directly with GitHub Pages. It includes sections for hero, about, skills, work experience, selected projects, AI/ML and automation journey, education, and contact.

## Local Preview

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

You can also open `index.html` directly in a browser because there is no build step.

## Deployment

1. Commit the updated static files.
2. Push to the `main` branch of `hemantachhami19/hemantachhami19`.
3. In GitHub, ensure Pages is configured to deploy from the `main` branch and repository root.

GitHub Pages will serve `index.html` automatically.

## Privacy Notes

The local CV was used only as a private reference for public-safe profile content. Resume and private document paths are ignored by `.gitignore`, including PDF and Word resume formats.

Do not commit private CV, resume, phone number, full address, or sensitive personal documents. The live site currently shows: "Resume available upon request."
